# Changelog

All notable changes to Chat Launcher. Newest entries are prepended
automatically by the release workflow from each GitHub Release's notes.

## [v1.2.0] — 2026-10-26

Per-country validation (≈60 countries + NANP) with live feedback, QR share
(vendored qrcode-generator), bulk launch, history notes, English + हिन्दी
i18n, four accent presets, local-only usage dashboard, native WhatsApp /
Telegram launches from desktop, CI (55 unit tests + 9 adversarial probes),
tag-driven EAS APK builds with checksums, Android launcher shortcuts.

## [v1.1.0] — 2026-10-25

Official brand glyphs (Simple Icons, CC0) on all tiles with current brand
colors; "app only" badge moved below the label (no more icon overlap);
Skype keeps a generic glyph (brand retired 2025).

## [v1.0.0] — 2026-10-25

First release: 9 launch targets (WhatsApp, Telegram, Signal, SMS, Call,
Viber, Skype, LINE, Threema), E.164 normalization with longest-prefix
country detection, installable offline PWA, share target, history,
dial pad, keyboard shortcuts, dark/light themes, security audit with
adversarial probes.
